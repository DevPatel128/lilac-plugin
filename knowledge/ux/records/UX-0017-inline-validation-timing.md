id: UX-0017
title: Validate after the field is done
kind: principle
domain: forms
claim: Flagging an error while the person is still typing is premature; checking on leave or at full length works.
guidance: Validate when the user leaves a field or when a fixed-length value is complete, then clear the error live as soon as it is fixed.
