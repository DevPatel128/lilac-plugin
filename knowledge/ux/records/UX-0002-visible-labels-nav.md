---
id: UX-0002
title: Visible labels on navigation and icons
kind: principle
domain: navigation
claim: Icons without a visible text label are ambiguous, and tab bars work best with few, labelled items.
guidance: Give every nav item and icon a visible text label. On mobile keep a bottom or top bar to about five items; move the rest into a clearly labelled More or menu entry.
evidence: Nielsen Norman Group, Icon Usability; https://www.nngroup.com/articles/icon-usability/; read 2026-11-21; figure: few icons are universal (home, print, search are exceptions) || Nielsen Norman Group, Mobile Navigation Patterns; https://www.nngroup.com/articles/mobile-navigation-patterns/; read 2026-11-21; figure: tab bars work best with about five options or fewer || Apple Human Interface Guidelines, Tab Bars; https://developer.apple.com/design/human-interface-guidelines/tab-bars; read 2026-11-21; figure: always include labels; fewer tabs are easier to navigate
confidence: high
applies_to: [website, webapp, mobile]
