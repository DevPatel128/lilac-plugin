id: UX-0005
title: Mega menus for large catalogues only
kind: pattern
domain: navigation
claim: Large sites can group many links in one visible two-dimensional panel; small sites do not need it.
guidance: Use a mega menu only when there are many sections: group under short distinct labels, list each link once, avoid widgets and hidden search, and wait about half a second before a hover menu opens.
evidence: Nielsen Norman Group, Mega Menus; https://www.nngroup.com/articles/mega-menus-work-well/; read 2026-11-21; figure: hover delay about half a second; show each choice once
confidence: low
applies_to: [website]
automated_check: manual
edges: [UX-0001]
