title: Never hide essential information in a tooltip
kind: principle
domain: content
claim: Tooltips are unavailable on touch screens and for many keyboard users.
guidance: Show rules (such as password requirements) as visible text; use tooltips only for brief extras reachable by keyboard.
evidence: Nielsen Norman Group, Tooltip Guidelines; https://www.nngroup.com/articles/tooltip-guidelines/; read 2026-11-21; figure: never hide vital task information like password rules
