---
id: UX-0007
title: Search is a visible box on every page
kind: pattern
domain: navigation
claim: A visible search field gets used more than a link to search.
guidance: On sites with more than a handful of pages put a text search box near the top of every page, wide enough to show a normal query. Treat the figure as dated.
evidence: Nielsen Norman Group, Search: Visible and Simple; https://www.nngroup.com/articles/search-visible-and-simple/; read 2026-11-21; figure: 2001 article: swapping a link for a search box raised search use by 91% on one site (dated, single site)
confidence: low
applies_to: [website, webapp]
automated_check: manual
edges: [UX-0086]
---
Note: single source; treat as a prompt to test, not a rule.
