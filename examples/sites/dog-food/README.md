# Biscuit & Bowl: demo dog-food website

A showcase of what Lilac's Website track can produce. **Biscuit & Bowl is a fictional sample brand, not a real company.** Products, prices (sample currency, BB$), ingredient lists and the feeding guide are placeholder text. No reviews, ratings, stock numbers, health claims or regulatory claims appear anywhere.

## What is in it

`site/` holds a static site in plain HTML, CSS and JavaScript: no build step, no framework, no external requests (system fonts, inline SVG).

- Pages: home, products (filter by life stage plus a "Choose a plan" builder), how it works, ingredients, FAQ, contact (browser-side validation, then "this is a demo, nothing was sent"), 404.
- Also: `robots.txt`, `sitemap.xml`, `favicon.svg`. The domain `example.com` in canonical and sitemap URLs is a placeholder (ASSUMED).
- Light and dark mode by `prefers-color-scheme`, tokens as CSS custom properties, skip link, visible focus, reduced motion respected. Motion is expressive but accessible: see the Motion section of BUILD-LOG.md. The nav and all reading work without JavaScript; the filter, plan builder and form check need it.

## Run it

```sh
node product-growth/media/demo-sites/serve.mjs dog-food 4173
# open http://127.0.0.1:4173/
```
